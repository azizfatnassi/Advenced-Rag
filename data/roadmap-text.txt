What You'll Understand:

Concepts:

Chunking Strategies:
Fixed size → simple but ignores meaning
Recursive character splitting → respects natural boundaries
Semantic chunking → splits by meaning change
Document-aware → respects headers, tables, paragraphs
Multi-Query Retrieval:
One query = one angle = missed chunks
Transform 1 query into 3-4 variations
Cover more semantic ground
Deduplicate results before sending to Mistral
Context Management:
Why local models like Mistral have limits
How too many chunks hurts answer quality
Hash-based deduplication

What You'll Understand:

Why similarity search alone is not enough

Concepts:

Re-Ranking:
Similarity search ranks by vector distance
Re-ranker uses a smarter model to re-order results
Cross-encoder models vs bi-encoder models
Why the top result is not always the best result
Hybrid Search:
Semantic search (what you have) → finds meaning
Keyword search (BM25) → finds exact terms
Combining both = better coverage
Important for finance (exact numbers, ticker names)
RAG Evaluation with RAGAS:

Answer Relevancy: does it actually answer the question?
Context Recall: did we retrieve the right chunks?
How to run RAGAS locally with Mistral

Week 3 — Advanced Indexing & Metadata Filtering

What You'll Understand:

How metadata makes retrieval smarter and faster
Parent-child chunk relationships
Hypothetical document embeddings (HyDE)
How to structure a financial document for maximum retrieval
Concepts:

Metadata Filtering:
Attach data to chunks: year, company, section, page
Filter BEFORE similarity search
Example: "only search 2023 documents"
Dramatically reduces noise
Parent-Child Chunking:
Small chunks for precise retrieval
Large chunks for full context to Mistral
Best of both worlds
HyDE (Hypothetical Document Embeddings):
Ask Mistral to write a hypothetical answer first
Embed THAT instead of the raw question
Hypothetical answer is closer in vector space to actual answer chunks
Resources:

"Parent Document Retriever" - LangChain docs
HyDE paper (original) - easy to read abstract
LangChain metadata filtering docs
Sam Witteveen - Advanced RAG YouTube
